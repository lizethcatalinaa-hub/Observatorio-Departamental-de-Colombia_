# Observatorio Departamental de Actividad Económica y Social

Aplicación interactiva para explorar, analizar y proyectar indicadores económicos y sociales de los departamentos de Colombia.

## Características

- Exploración de series temporales y rankings
- Análisis Exploratorio de Datos (EDA) + correlaciones
- Clustering (KMeans, Hierarchical, DBSCAN)
- PCA
- Machine Learning (Ridge, Lasso, ElasticNet, SVR, RandomForest, GradientBoosting, OLS)
- Modelos VAR y VECM
- Mapas coropléticos de Colombia
- Redes LSTM para pronósticos
- Simulación de escenarios
- Interpretabilidad de modelos

## Fuentes de datos

- DANE
- datos.gov.co
- DNP
